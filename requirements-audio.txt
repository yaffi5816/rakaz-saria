# versions of the agent stay comparable on the same short list of libraries.
#

#

# bundle of ONNX runtime pieces - a few hundred megabytes - and then the model
# itself downloads on first use: about 1.5 GB for medium, 3 GB for large-v3.
# On a filtered connection, start it when you have the afternoon.
#
# RAKAZ_STT=server needs none of this: it posts the file to a transcription
# service on your own network and only httpx is involved, which is already
# pinned in requirements.txt.
