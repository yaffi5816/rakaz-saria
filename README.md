# רכז — סוכן אחד, שני harnesses

סוכן שהופך סיכום ישיבה בעברית למשימות מסודרות במערכת ניהול משימות ופרויקטים:
מוצא את הפרויקט והאנשים, בודק תאריכים מול לוח השנה העברי, מכין טיוטה, וכותב
למערכת רק אחרי אישור מפורש. הוא זוכר בין סשנים איך האגף עובד, ומסרב לבצע בקשה
שסותרת החלטה ניהולית שנשמרה.

אותו סוכן בדיוק בנוי כאן פעמיים:

* **`API/`** — על ה-Messages API הגולמי, עם harness שכתוב ביד: לולאה, כלים,
  היסטוריה, זיכרון, קונטקסט, compaction, caching ומדידת טוקנים.
* **`SDK/`** — על Claude Agent SDK, שבו ה-harness הוא של Claude Code ואני רק
  מגדירה אותו.

`shared/` מחזיק את קוד הדומיין — הכלים, הנתונים והכללים — ושתי הגרסאות משתמשות
בו. ההשוואה ב-[REPORT.md](REPORT.md) נשענת על כך שזה באמת אותו סוכן.

## הרצה

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
cp .env.example .env
```

גרסת ה-API צריכה מפתח מ-Claude Console, כמשתנה סביבה בטרמינל בלבד — לא בקוד ולא
ב-git:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
python API/main.py --scenario scenario.json --out results/api.json
```

גרסת ה-SDK רצה על ה-login שלך ב-Claude Code, וחייבת טרמינל שבו המפתח **לא**
מוגדר — אחרת החיוב עובר למפתח. `SDK/main.py` נופל עם הודעה ברורה אם הוא מוצא
אותו. (התיעוד של ה-SDK מדבר על `ANTHROPIC_API_KEY` ולא מאשר במפורש נפילה חזרה
ל-login; אם הריצה הראשונה תתלונן על אימות, זה המקום לבדוק.)

```bash
unset ANTHROPIC_API_KEY
python SDK/main.py --scenario scenario.json --out results/sdk.json
```

הבדיקות רצות offline, בלי מפתח ובלי רשת:

```bash
python -m pytest tests/ -q    # 37 בדיקות
```

## מה הסוכן יודע לעשות

תשעה כלים, מוגדרים פעם אחת ב-`shared/tools.py` ונצרכים על ידי שתי הגרסאות:

| כלי | מה הוא עושה |
|---|---|
| `read_transcript` | **קבצים**: תמלול ישיבה (vtt/txt/md), או הקלטה שמתומללת אוטומטית |
| `search_workspace` | משימות, פרויקטים ואנשים — מוגבל למה שהמשתמשת רשאית לראות |
| `workload` | כמה משימות פתוחות ובאיחור יש לכל אדם |
| `calendar_check` | **חיצוני**: hebcal.com — שבת, חג, ויום העבודה הקרוב |
| `history_stats` | כמה זמן באמת לקחו בעבר משימות דומות |
| `draft_plan` | מכין טיוטה, לא כותב כלום |
| `commit_plan` | כותב רק את המשימות שאושרו בשמן, אחת-אחת |
| `remember` | שומר כלל עבודה או החלטה ניהולית |
| `recall` | שולף את מה ששמור בנושא מסוים |

## איפה המצב נשמר

```
memory/profile.md          איך האגף עובד — קבוע, נכנס לכל תור (ב-SDK: CLAUDE.md)
memory/conventions.jsonl   כללים והחלטות, append-only. ביטול מוסיף שורה
state/workspace.db         עותק מזורע של מערכת המשימות
state/history/*.jsonl      התמליל של כל סשן, append-only
state/drafts.json          טיוטות, עם סטטוס אישור לכל משימה בנפרד
shared/fixtures/meetings/  תמלולי ישיבות לקריאה
```

## להעלות הקלטה

`read_transcript` מקבל גם קובץ אודיו — `m4a` מהטלפון, `mp3`, `wav`, `opus`.
הוא מתמלל, שומר `.vtt` ליד ההקלטה, וקורא אותו. קריאה שנייה לאותו קובץ לא
מתמללת שוב.

איפה התמלול רץ נקבע ב-`RAKAZ_STT`, וזאת ההחלטה היחידה שחשובה כאן:

| | מה קורה | מה צריך |
|---|---|---|
| `local` | faster-whisper בתהליך הזה. ההקלטה לא עוזבת את המחשב | `requirements-audio.txt` והורדת מודל חד-פעמית |
| `server` | העלאה לשירות תמלול ברשת הארגונית (OpenAI-compatible) | `RAKAZ_STT_URL` בלבד |
| `off` | הקלטה נדחית עם הסבר מה להדליק | — |

**שתי מגבלות שכדאי לדעת מראש.** תמלול מהקלטה **לא מזהה דוברים** — Whisper
מחזיר מה נאמר ולא מי אמר, אז הסוכן נשען על המילים עצמן ("דנה תכין...") ולא על
תווית. התמלול שטימס מייצר כן נושא שמות, ולכן הוא עדיין העדיפות הראשונה. ובמנוע
המקומי על מעבד, ישיבה של שעה לוקחת בערך שעה.

אף בדיקה לא מריצה זיהוי דיבור אמיתי: `tests/test_audio.py` מחליף את המנוע
במדומה ובודק את הניתוב, את המטמון ואת ההודעות. גם הריצות המדודות לא נוגעות
באודיו — התרחיש עובד על תמלול, כדי שהמספרים יהיו ניתנים לשחזור.

## מרחב העבודה

ברירת המחדל היא `RAKAZ_WORKSPACE=local` — עותק SQLite שנזרע מ-
`shared/fixtures/workspace.json`, ונמחק ונבנה מחדש בתחילת כל ריצה. זה מה שמאפשר
להשוות שתי ריצות, וזה מה שכל הבדיקות רצות מולו.

`RAKAZ_WORKSPACE=http` מפנה את אותו סוכן אל מופע חי של אפליקציית המשימות דרך
HTTP (`RAKAZ_API_BASE`), בשביל הדגמה: מריצים את התרחיש, פותחים את מסך המשימות,
והמשימות שם. אין בדיקה אחת שנוגעת במסלול הזה, וכדאי להפעיל אותו רק מול סביבת
פיתוח עם נתוני דמה — תוכן המשימות נשלח למודל.

**הנתונים ב-`shared/fixtures/` מומצאים לחלוטין.** אין בהם אדם, פרויקט או תקציב
שמתכתב עם משהו אמיתי.
