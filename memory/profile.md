# איך עובד אגף סקרים

- המנהלת היא שרה אביטל. הסוכן פועל בשמה ורואה רק מה שהיא רשאית לראות.
- שבוע העבודה ראשון עד חמישי. אין תאריכי יעד בשישי, בשבת ובחגים.
- לכל משימה חייב להיות אחראי אחד לפחות. שותף מסייע ואינו נושא באחריות.
- פרויקט מחולק לרצועות: הכנה, שדה, עיבוד. משימה חדשה נכנסת לרצועה המתאימה.
- מצגות ודוחות להנהלה מוגשים עד ה-5 לחודש.
- כשמשימה תלויה בקודמתה, מסמנים תלות במקום לכתוב את זה בתיאור.
